# General Report Skill（通用报告方法论）

## 使命

从导入资料与注册信源生成可溯源、可核验、可交付的通用报告（调研、分析、深度报告等）。**先结构化、再渲染**；每个事实性陈述可回溯到资料原文页；检查失败阻止验收。本技能只承载方法与流程；任务分解、成稿与反思由受理的 agent 自主完成，编排器（确定性流水线）只注入运行时数据与输出协议。

## 与 annual-report 的关系

- **共用**：确定性核验纪律（数值核验 N 系 + 引用核验双层）、引用体例（digest/page/excerpt 三元组与 [C-n] 标注）、信源权威分级、fail-closed 门禁、长文输出协议。
- **差异**：
  1. **骨架**：节清单、标题、静态节正文模板、各节责任 agent 全部来自 `report-structure.json` 的 `report_types.general`（编排器按 report_type 注入），本技能不内嵌任何固定章节；
  2. **指标**：通用域报告可能没有 8 项标准指标——任务书指标表可能缺失或为空，此时正文只引用任务书注入的资料原文，不做指标完整性假设；
  3. **主题**：任务目标来自「报告主题」（subject_hint），不是固定银行年报。

## 角色与铁律

| 角色 | 必读 | 铁律摘要 |
|---|---|---|
| 长文写作（writer-agent） | `references/long-form-writing.md` | 受理任务书自主分解、逐节成稿；[C-n] 标注；违规反馈只改受影响节；输出协议不变 |
| 主笔 | 编排注入的引用清单 | 论断只来自资料与引用清单；修订只动指令指定项 |
| 核验员 | 本文件「核验协议」节 | FAIL 打回一次；再 FAIL 或语义存疑转 waiting_human；绝不放行 |

## 长文写作（long_form 流水线）

长文模式由写作类 agent（如 writer-agent）受理编排器下发的「长文写作任务书」：

1. 先用 skill_tool 加载本技能与 `references/long-form-writing.md`（长文方法与流程的唯一事实源）；
2. 按方法自主分解章节写作计划（可用框架 todo 工具），逐节成稿；
3. 严格遵循任务书的输出协议（块首行仅 `[S-n]`，正文从下一行开始）——该协议是服务端解析契约；
4. 收到核验违规反馈时，按 `references/long-form-writing.md` 的修订响应流程自纠。

长文硬性纪律（任务书/续写/修订任何轮次都不得让步；写作细则见 reference）：

- **篇幅**：每节正文 600-1200 字，总-分-收结构，中段不少于两个自然段；低于 600 字视为该节未完成，不得交付；
- **口径**：任务书注入的值与单位一字不改；不得编造资料原文之外的数字；
- **引用**：涉及事实与数据的论断逐条带任务书 [C-n] 引用标注，不得虚构或挪用引用编号；
- **交付通道**：本轮要交付的全部成稿块必须在最终答复中完整输出——最终答复是编排器唯一解析对象，中间轮次的构思、草稿与 todo 记录不算交付；
- **格式精度**：块首行 `[S-n]` 与引用标注 `[C-n]` 的方括号内不加空格（写 `[G-4]`，不写 `[ G-4 ]`）；最终答复从第一个块开始、到最后一个块结束，首尾不得附加总结或说明文字；
- **增量**：续写轮只输出缺失节，修订轮只输出受影响的节，未涉及的节不要重复输出。

## 核验协议（fail-closed）

1. **数值核验（确定性，无模型）**：通用域无指标时数值核验自动跳过指标完整性检查（metrics 为空/null 合法）；有指标记录时按年报域同一纪律校验（单位白名单、页内字面命中、变动口径）。
2. **引用核验（双层）**：L1 确定性——digest/page/excerpt 逐条比对，伪造/篡改即 BLOCKING；L2 语义——支持度三级 SUPPORTED/PARTIAL/UNSUPPORTED，PARTIAL 转 WARNING+人工，UNSUPPORTED 即 BLOCKING。
3. **信源纪律**：引用页必须在注册信源（快照集，含用户导入资料的 live 快照集）覆盖内；正文事实不得超出快照页原文。
4. **门禁状态机**：PASSED→deliverable；FAILED round=0→定向修订一次；FAILED round=1 或 WAITING_HUMAN→人工接管。修订上限=1。

## 已知限制（如实声明）

- 通用域不提供领域指标字典（各领域口径差异大，按需由调用方在任务书内注入口径说明）；
- 语义支持度灰区由 LLM Critic 兜底但最终转人工，不由 judge 单独批准；
- 年报域默认冻结快照；通用域可经 deep-search agent 联网补充（抓取产物须 snapshot_commit 落盘注册后方可引用）。
