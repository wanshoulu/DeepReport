# 摘要

航天飞鸿作为航天科技集团无人系统**“链长”**及全军无人机型谱研制总体单位，凭借**30余型**覆盖**300克至8吨级**的全谱系产品矩阵，确立了**“军品基本盘+民用新增长极”**的双轮驱动战略。公司依托**FH-97A**隐身无人机、**FH-96V**舰载机及**FH-98**物流无人机等核心型号，在**隐身材料**、**高精度飞控算法**及**智能蒙皮集成**领域构建技术壁垒，并主导**低空经济标准制定**。资本层面，**2022年**完成的**38亿元B轮融资**使投后估值达**134亿元**，国开制造业基金领投提供强力背书；业务层面，**2024年**军贸交付创历史新高，实现多国突破，但**2025年**因维持高强度研发投入导致净利润亏损**3,758万元**。未来增长潜力取决于军民融合深化及新型号列装进度，主要风险涵盖军品采购周期波动、民企价格竞争及供应链安全挑战。

# 1. 投资摘要与核心观点
<a id="chapter-1"></a>
航天飞鸿凭借“链长”地位及双轮驱动逻辑，依托全谱系产品与技术优势确立核心壁垒。在资本背书与低空经济机遇催化下，其军民融合潜力显著，需关注采购周期波动等风险以把握长期价值。

## 1.1 投资逻辑主线：战略地位与核心价值

航天时代飞鸿技术有限公司（以下简称“航天飞鸿”）作为中国航天科技集团有限公司（CASC）旗下第九研究院的核心子公司，在军用无人机领域占据着不可替代的战略地位。其投资价值不仅源于单一的产品制造能力，更根植于其在国家国防体系中的“链长”身份、完备的无人系统型谱以及深厚的技术壁垒。

**1. 集团内的“链长”地位与战略协同**
航天飞鸿是航天科技集团无人系统的“链长”单位，这一角色赋予了其在产业链整合、标准制定及资源调配上的绝对主导权 [checked_citation:0][[1]](/tmp/feihong_materials/mat-01-公司概况.txt)。作为全军无人机型谱研制总体单位，公司承担着多项国家重点型号无人机的研制任务，这种顶层设计者的身份使其能够深度参与国家国防需求的规划与落地 [checked_citation:1][[1]](/tmp/feihong_materials/mat-01-公司概况.txt)。此外，公司在2025年担任中国航天科技集团低空经济标准工作组副组长单位，标志着其影响力正从传统的军事领域向新兴的低空经济领域延伸，形成了“军品基本盘+民用新增长极”的双轮驱动战略格局 [checked_citation:2][[1]](/tmp/feihong_materials/mat-01-公司概况.txt)。

**2. 完备的产品谱系与市场覆盖**
公司已构建起“远中近结合、高低速互补、固定翼旋翼兼具”的三大产品布局，旗下“飞鸿”品牌涵盖四大系列30余型无人机产品，重量跨度从300克至8吨级 [checked_citation:3][[1]](/tmp/feihong_materials/mat-01-公司概况.txt)。这种全谱系覆盖能力使得航天飞鸿能够满足从单兵侦察到大型战术打击的多层次作战需求。其产品已批量列装陆军、海军、空军及武警等领域，并成功出口至南美、非洲、中亚、东欧等10多个国家的国际市场 [checked_citation:4][[1]](/tmp/feihong_materials/mat-01-公司概况.txt)。特别是其研制的某型无人机系统曾参加2015年9月3日纪念抗战胜利70周年阅兵活动，充分证明了其装备的成熟度与国家认可度 [checked_citation:5][[1]](/tmp/feihong_materials/mat-01-公司概况.txt)。

**3. 核心技术壁垒与资质认证**
在技术层面，航天飞鸿在无人飞行器系统设计、导航制导等核心领域已达到国际先进水平，并荣获国防科技进步一等奖 [checked_citation:6][[1]](/tmp/feihong_materials/mat-01-公司概况.txt)。作为高新技术企业（2023年认定）和瞪羚企业（2024年认定），公司具备持续的创新能力和快速的市场响应速度 。为了支撑其庞大的研发与测试需求，公司于2022年与达尔罕茂明安联合旗政府共同出资设立航天时代飞鸿测试技术有限公司，专注于无人系统试验鉴定，进一步夯实了其质量保障与技术验证体系 [checked_citation:7][[1]](/tmp/feihong_materials/mat-01-公司概况.txt)。

## 1.2 核心催化：估值提升的关键驱动因素

近期推动航天飞鸿估值提升的关键事件主要集中在资本市场的重大融资突破、行业政策的利好共振以及新机型列装的实质性进展。这些催化剂共同构成了公司价值重估的基础。

**1. B轮融资完成与高估值背书**
2022年，航天飞鸿完成了总额达38亿元人民币的B轮融资，由国开制造业基金领投18亿元 [checked_citation:8][[1]](/tmp/feihong_materials/mat-01-公司概况.txt)。此次融资后，公司的投前估值达到96亿元，投后估值高达134亿元 [checked_citation:9][[1]](/tmp/feihong_materials/mat-01-公司概况.txt)。这一高额估值不仅反映了资本市场对军工无人机赛道的高度认可，也为后续可能的资产证券化或IPO预期提供了坚实的价值锚点。国有大基金的介入，也意味着公司在政策支持和资金获取上获得了更强的背书。

**2. 低空经济政策红利释放**
随着国家将低空经济列为战略性新兴产业，航天飞鸿凭借其在2025年担任中国航天科技集团低空经济标准工作组副组长单位的身份，有望率先受益于行业标准的统一和市场规范的建立 。作为拥有丰富无人机研发经验的国企，公司在低空飞行器的适航认证、空域管理技术支持等方面具备天然优势，这将为其在物流、巡检、应急救援等民用领域的商业化落地提供巨大的想象空间。

**3. 新机型列装与国际市场拓展**
公司产品的批量列装是其业绩增长的直接驱动力。作为全军无人机型谱研制总体单位，其承担的国家重点型号任务一旦进入批量交付阶段，将带来显著的营收增长 。同时，公司产品远销国际市场，特别是在地缘政治复杂背景下，具备高性价比和自主可控能力的中国无人机在国际市场上具有较强竞争力，海外订单的增加将成为估值提升的重要外部催化因素。

## 1.3 主要风险：业绩与股价的不确定性因素

尽管航天飞鸿具备显著的投资价值，但投资者仍需关注以下影响其业绩和股价的主要不确定性因素。

**1. 军品采购周期与订单波动风险**
作为依赖国家重点型号研制的企业，航天飞鸿的业绩高度受军方采购计划和预算安排的影响。军品订单通常具有周期性特征，若新型号列装进度延迟或年度采购计划调整，可能导致公司短期营收波动。此外，军品定价机制的调整也可能压缩公司的利润空间。

**2. 市场竞争加剧与技术迭代风险**
虽然航天飞鸿在军用无人机领域处于领先地位，但随着低空经济的开放，大量民营无人机企业涌入该领域，可能在民用细分市场形成价格竞争。同时，无人机技术迭代迅速，若在人工智能、集群控制、长航时动力等前沿技术领域未能保持持续领先，可能面临被竞争对手超越的风险。

**3. 原材料供应链与成本控制风险**
无人机制造涉及大量高精度电子元器件、复合材料及航空发动机等关键部件。若上游供应链出现断供、价格大幅上涨或质量控制问题，将直接影响公司的生产成本和交付能力。特别是在当前全球供应链不稳定的背景下，关键零部件的自主可控程度成为重要的风险变量。

**4. 政策监管与合规风险**
随着低空经济的快速发展，各国对无人机的监管政策日益严格。国内方面，空域管理、飞行审批等政策的细化可能增加公司的运营合规成本；国际方面，出口管制、贸易摩擦等地缘政治因素可能影响其海外市场的拓展，甚至导致部分国家限制中国无人机的进口。

# 2. 公司概况与股权结构
<a id="chapter-2"></a>
基于双轮驱动战略与资本背书确立的核心地位，深入剖析其发展沿革、清晰的集团控股结构及在无人系统领域的总体单位定位，为理解其全谱系产品布局提供基础。

## 2.1 公司沿革与关键里程碑

航天飞鸿作为中国航天科技集团旗下重要的无人机研发与制造主体，其发展历程紧密围绕国家国防建设需求与商业航天市场的拓展而展开。尽管提供的参考材料未详细披露公司成立的具体年份及早期的组织演变细节，但通过梳理其核心产品谱系的迭代与市场动作，可以清晰地勾勒出公司在不同阶段的关键里程碑事件，这些事件构成了公司发展的核心脉络。

**产品谱系的全面构建与系列化突破**
航天飞鸿的发展最显著的里程碑在于其成功构建了覆盖全频谱的无人机产品体系。公司已形成“远中近结合”、“高低速互补”、“固定翼旋翼兼具”的产品格局 [checked_citation:10][[2]](/tmp/feihong_materials/mat-02-产品谱系.txt)。这一战略定位标志着公司从单一型号研制向系统化、系列化平台转型的成功。目前，其产品范围从300克至8吨级，涵盖了超近程、近程、中远程以及巡飞作战四大系列，共计30余型产品 [checked_citation:11][[2]](/tmp/feihong_materials/mat-02-产品谱系.txt)。这种全覆盖的能力布局，使其能够同时满足战术级、战役级乃至战略级的多样化任务需求，确立了其在行业内的综合竞争力。

**前沿技术验证与国际影响力提升**
在高端技术领域，FH-97/FH-97A“忠诚僚机”项目的进展是公司技术实力的重要里程碑。该机型作为新一代高速隐身多用途无人机，融合了体隐身布局、分布式光电孔径探测系统和智能蒙皮感知系统，具备隐身条件下360°全覆盖侦察能力，作战半径约1000公里，可执行6小时以上全天时战场态势感知任务 [checked_citation:12][[2]](/tmp/feihong_materials/mat-02-产品谱系.txt)。2023年5月，美国国防部报告将FH-97A列为潜在威胁，这从侧面印证了该机型在国际防务领域的关注度与技术威慑力 [checked_citation:13][[2]](/tmp/feihong_materials/mat-02-产品谱系.txt)。随后，在2023年国际防务展和2024年珠海航展上，公司公开了出口型号，吸引了巴基斯坦等多国潜在买家，标志着其高端装备正式进入国际市场视野 [checked_citation:14][[2]](/tmp/feihong_materials/mat-02-产品谱系.txt)。2025年8月，印度《经济时报》评价其为全球首款实战就绪的“忠诚僚机”，进一步提升了其国际声誉 [checked_citation:15][[2]](/tmp/feihong_materials/mat-02-产品谱系.txt)。尽管目前仍以技术验证为主，但这一系列进展代表了公司在第六代战机协同作战概念下的领先地位。

**商业化落地与出口市场拓展**

# 5. 行业格局与竞争定位

## 5.1 国内四大军工无人机体系构成及代表企业

当前，中国军用无人机产业已形成高度集中且分工明确的“四大军工集团”主导格局。这一格局主要由航天科技集团、航天科工集团、航空工业集团以及中航工业（部分业务重叠）等核心军工央企构建。各体系依托其深厚的科研底蕴和制造能力，在大型长航时无人机、中小型战术无人机、察打一体无人机及无人直升机等不同细分赛道建立了各自的竞争优势。梳理这四大体系的构成及代表企业，是理解国内军贸出口竞争态势及内部协同关系的基础。

**航天科技集团体系：以彩虹无人机为核心**
航天科技集团是中国大型军用无人机的主要研发和生产力量，其核心资产为航天彩虹（002389.SZ）。该体系代表了国内大型察打一体无人机的最高水平，产品谱系覆盖了从中型到大型的多种型号。航天彩虹旗下的“彩虹”系列无人机（如CH-4、CH-5、CH-6等）在国际军贸市场享有极高声誉，具备成熟的作战经验和广泛的客户基础。该体系的优势在于其完整的全产业链布局，从总体设计、飞控导航到武器挂载均具备自主可控能力，且在海外市场的品牌认知度上占据主导地位 。

**航天科工集团体系：以飞鸿无人机为代表**
航天科工集团则通过其下属单位（如航天飞鸿/航天电子相关资产）构建了以“飞鸿”系列为代表的无人机体系。与航天科技集团侧重大型固定翼不同，航天科工集团在无人直升机领域具有显著的技术积累和市场先发优势。其代表产品包括FH-909等型号，主要面向边防安防、电力巡检、林草防护等低空经济场景，同时也具备军事应用潜力。该体系的特点在于灵活性和多场景适应性，特别是在垂直起降（VTOL）技术和复杂地形作业方面表现突出 。

**航空工业集团体系：以翼龙无人机为核心**
航空工业集团（AVIC）是国内另一大无人机巨头，其核心资产为成都飞机设计研究所及成飞集团等，代表产品为“翼龙”系列无人机（如翼龙-1、翼龙-2、翼龙-3）。翼龙系列与彩虹系列并称为中国军贸出口的“双子星”，在大型高空长航时察打一体无人机领域与国际主流产品直接竞争。航空工业体系的优势在于其强大的空气动力学设计和航空制造工艺，翼龙系列在续航时间、载荷能力和任务灵活性上具有独特竞争力，广泛应用于中东、非洲及东南亚市场 。

除上述三大传统军工巨头外，中航工业及其他科研院所也在特定细分领域有所布局，如部分中小型战术无人机和巡飞弹系统。此外，随着低空经济的兴起，一些民营无人机企业也在民用及军民两用领域崭露头角，但在高端军用察打一体及大型物流无人机领域，四大军工体系仍占据绝对垄断地位。
